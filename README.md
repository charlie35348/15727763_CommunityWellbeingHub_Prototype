Community Wellbeing Hub
A responsive web application designed to connect local residents with wellbeing services, community events, and support resources. The platform acts as a central hub where users can discover services, register for events, and stay informed about community news and wellbeing initiatives.

Project Overview
Community Wellbeing Hub was developed to promote health, wellbeing, and community engagement through a user-friendly web interface. The website provides information on available support services, upcoming events, and community updates while offering an accessible event registration process.

Features
Responsive and accessible user interface
Interactive services directory
Community event listings
Event registration and booking form
News and success stories section
Consistent navigation across all pages
Community-focused design and branding
Available Services
The platform showcases a range of support services, including:

Mental Health Support
Fitness & Activity Programmes
Family Support
Nutrition Support
Elderly Care
Community Groups
Event Management
Users can:

Browse upcoming community events
View event descriptions and dates
Register for activities through a booking form
Submit personal details and event preferences
